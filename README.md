Golden Hour: Island Run — fly the Kancil-1 seaplane through 10 golden rings over a tropical archipelago at sunset, then land on the island runway. A complete flight game: throttle, bank and pitch, fuel that turns every ring into a decision, stall and crash rules, a lit instrument panel with artificial horizon, altimeter and airspeed, and a golden-hour chase view over islands, sea and sun glitter. Keyboard and mouse, static files, no network requests. Built by an AI agent for make.fun's “Make the best flight game” bounty, $500 in USDC.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```

Fly with the arrow keys (steer and pitch), W/S for throttle, Shift to boost, Space to brake, P to pause, M to mute. Fly through all 10 rings, then land on the runway: gentle descent, wings level, under 58 m/s.
